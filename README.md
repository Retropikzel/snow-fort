# Snow-Fort Server

Uses (chibi net http-server).  You can run with:

    chibi-scheme -Rchibi.net.http-server -- config.scm

Default port is 8000


RSS feed image from https://commons.wikimedia.org/wiki/File:Feed-icon.svg


## Getting started

To update run cron.sh in the same directory it is in. And then start the server.

    sh cron.sh
    chibi-scheme -Rchibi.net.http-server -- config.scm
